# Telegram Dictionary Tutor Bot (.NET 10)

Асинхронный Telegram-бот на платформе .NET 10 для интерактивного изучения и повторения английских слов. Проект спроектирован с учетом гибридного хранения данных (In-Memory Cache + Persistence Layer) для минимизации нагрузки на дисковую подсистему.

---

## 🛠 Архитектурные особенности проекта

При проектировании архитектуры были решены классические проблемы высоконагруженных систем:

1. **Гибридное хранилище (In-Memory Caching + Persistence)** 
* **Проблема:** Постоянное чтение словаря с диска при каждом запросе пользователя создает бутылочное горлышко (I/O Bottleneck) и перегружает процессор.
   * **Решение:** На старте приложения происходит однократный «прогрев кэша» — данные из файла `wordstorage.txt` вычитываются в быструю коллекцию `Dictionary` в оперативной памяти. Все операции поиска (`CheckWord`, `Translate`, `GetRandomEngWord`) выполняются в памяти со сложностью поиска **$O(1)$**. Запись на диск производится асинхронно только при добавлении новых уникальных записей.

2. **Secrets Management (Безопасность учетных данных)** 
* Конфиденциальные данные (Telegram API Token) полностью изолированы от исходного кода приложения.
  * Интегрирована библиотека `dotenv.net`, загружающая переменные окружения из файла `.env`. Файл `.env` добавлен в `.gitignore` для предотвращения случайной компиляции токенов в публичный репозиторий.

3. **Жизненный цикл сервисов (Services Lifetime)** 
* Класс `Tutor` инициализируется в единственном экземпляре (аналог Singleton) на уровне точки входа `Program.Main`. Это гарантирует консистентность словаря в памяти для всех параллельных сессий пользователей и предотвращает утечки памяти.

4. **Кастомная обработка ошибок (Domain Exception Handling)** 
* Реализовано пользовательское исключение `FoundDublicateException` для управления бизнес-логикой при попытке добавить уже существующее в кэше слово.

## 💻 Технологический стек

* **Платформа:** .NET 10 (C#) 
* **Telegram API Wrapper:** `Telegram.Bot` SDK (асинхронное получение обновлений через Long Polling)
* **Конфигурация:** `dotenv.net` для работы с переменными окружения

## 🚀 Быстрый запуск

### 1. Клонирование репозитория
```bash
git clone https://github.com/sherlockteen/TelegramTutorBot.git
cd TelegramTutorBot
```
### 2. Настройка переменных окружения

В корневой директории проекта создайте файл ```.env```  и добавьте ваш токен, полученный от @BotFather:
```bash
TELEGRAM_BOT_TOKEN=ваш_токен_бота
```

### 3. Запуск приложения

Скомпилируйте и запустите проект через .NET CLI:
```bash
dotnet restore
dotnet run
```

## Список поддерживаемых команд
- /start — вывод приветственного сообщения и списка доступных команд.
- /add <eng> <rus> — добавить новую пару слов в словарь (с валидацией на дубликаты прямо в памяти).
- /get — получить случайное английское слово для тренировки перевода.
- /check <eng> <rus> — проверить правильность вашего перевода (проверка регистронезависимая).
